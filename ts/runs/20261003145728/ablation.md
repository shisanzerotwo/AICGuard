# 防御层消融实验（T3）

逐个开关 N1（编码归一化）/ G1（输入规则）/ G2（输出兜底），量化每层的独立贡献。

| 防御配置 | ASR | 被攻破 | 输入拦截 | 输出兜底 |
|---|---|---|---|---|
| 无防御（基线） | 85.6% | 320/374 | 0 | 0 |
| 仅 N1 归一化 | 86.1% | 322/374 | 0 | 0 |
| 仅 G1 输入规则 | 40.1% | 150/374 | 170 | 0 |
| **N1 + G1（无输出兜底）** ← 关键行 | 5.6% | 21/374 | 301 | 0 |
| 仅 G2 输出兜底 | 4.3% | 16/374 | 0 | 306 |
| 全部启用 | 4.3% | 16/374 | 301 | 5 |

## 结论

基线（无防御）ASR 为 85.6%。仅开 G1 输入规则可降到 40.1%；叠加 N1 归一化后进一步降到 **5.6%** —— **归一化层单独贡献 34.5 个百分点**（40.1% → 5.6%）。

这解释了为什么编码混淆是关键词防御的头号杀手：关键词规则看不懂编码内容，而模型看得懂。先归一化再检测，不需要改动模型就能堵住这一整类攻击——「归一化层必须在下游规则之前」这条设计决策由此获得量化支撑。

> 注：「仅 N1」单独看与基线相同是**正确**的——归一化只做还原，本身不拦截；它的价值必须与 G1 组合才能观察，所以关键行是「N1 + G1」。

> 注：G2 输出兜底的 ASR 与「全部启用」相同是**预期行为**——它兜住了输入侧漏掉的攻击，但输入侧拦下的条数不会变。两层是互补关系，不是重复建设。
