# 安全阈值权衡扫描（T2）

- 用例：374 条攻击 + 105 条阴性对照；规则：母语 + 机翻合并
- 推荐工作点：**阈值 0.50**（误报约束内）
- 推荐理由：在误报率 ≤ 5.0% 的约束下，阈值 0.50 的输入侧攻击成功率最低（5.6%），误报率 0.0%。

## 结论

整体 ASR（叠加输出兜底）在全部阈值下介于 4.3% ~ 4.3% 之间（极差 0.0 个百分点），**对阈值几乎完全不敏感**；而输入侧 ASR 随阈值在 5.6% ~ 84.5% 之间大幅变化，输入侧误报率则反向变化。阈值确实是有效的调节旋钮，但它只作用于输入侧。

曲线上的台阶来自规则权重分布（有害内容 0.95 / 覆盖指令 0.75 / 套取提示与角色扮演 0.70）。把误报率与拦截率的权衡摊开给业务方选工作点，比替他们拍板一个数更负责任——这也是本平台与「只给一个成功率数字」的普通扫描工具的差异之一。
