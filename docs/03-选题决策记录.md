## 二、为什么选 AICGuard

| 判据 | AICGuard | 声动 |
|---|---|---|
| 数据依赖 | **零** | 需 50 位维/哈语母语者录音 |
| 组织成本 | **零** | 需 3 位教师盲评 + 1 个班级试点 |
| 当前状态 | **已跑通，指标齐全** | 核心代码已写，依赖未装、未验证 |
| 环境依赖 | **零第三方依赖** | librosa / parselmouth / scipy / soundfile 等 |
| 风险性质 | 分数可能不够高 | **可能整个项目做不出来** |

声动的分数上限更高（应用价值与地域相关性更强），但它把整个项目建立在"能否招到 50 位母语者录音"上，且团队自设的换题死线是 10/07。省赛要在 30 天内稳定交付，选确定能交出来的那个。
