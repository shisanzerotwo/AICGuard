## 1. 项目是什么

**AICGuard · 中文大模型安全评测与护栏平台**——给大模型应用做上线前的"安全体检"：
用自建的中文母语攻击用例库发起自动化评测，量化攻击成功率（ASR）与防御效果，并**逐条归因**
是哪一层防御失效、为什么、怎么修。与普通扫描工具的分水岭就是"归因 + 修复建议"。

参赛：AIC 第八届全球校园人工智能算法精英大赛 · 新疆赛区 · AI+软件创新赛道（省赛 2026-10-31 前）。

|---|---|

## 6. 铁律（违反会导致返工）

### 6.1 技术栈

- **零第三方依赖**：核心引擎只用 Node 内置模块；不用 `npm install`（promptfoo 是唯一例外，
  锁在独立目录 `ts/promptfoo/`，MIT，不进主链路）。
- **Node strip-only 限制**：不用 TS 参数属性 `constructor(private x)` / `enum` / `namespace` /
  装饰器——会直接报 `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX`。用显式字段赋值 + `const` 对象 + `as const`。

### 6.2 数据

- `data/*.jsonl` 字段名与用例**不要删改**——机翻用例、"刻意留出的防御缺口"用例是实验结果的一部分。
- 语料逐条必须带 `source` 与 `notes`（构造意图/溯源）；新增对照组沿用该纪律（见 garak 组先例）。

### 6.3 指标口径

- **unclear 不计入 ASR 分母**（API 失败、判不准都不计，别改）。
- **每条指标可复现**：不允许手写数字；对外引用带口径（严格/广义；多次采样时给逐轮 + 池化 + 95% CI）与日期。
- 真实模型 API 失败 ≠ 防住了：`targetError` 必须透传为 unclear（含误报率分母）。

### 6.4 成本与安全

- 真实模型跑批前打印预估请求数，**>200 次必须 `--yes`**；缓存键含 (salt, model, system,
  temperature, maxTokens, messages)，改任一项自动失效。
- **密钥只在 `ts/.env.local`（已 gitignore）**；任何源码/文档/发布包不得出现 `sk-`。
- `scripts/release.mjs` 打包自带安全自检，别绕过。

### 6.5 代码风格

- 注释用中文解释**为什么**；模块顶部写清楚解决什么问题；与现有文件风格一致。

## 7. 核心设计决策（改之前先读）

| 决策 | 理由 | 改动的后果 |
|---|---|---|
| 金丝雀机制（系统提示埋随机串） | 把"感觉泄露了"变成确凿泄露，判定客观 | 系统提示泄露无法客观判定 |
| 判定前先做编码还原 | 模型用 Base64 输出泄露绕过明文检测 | 这类泄露成为盲区 |
| 归一化层在规则之前 | 关键词看不懂编码内容，模型看得懂 | 编码混淆族失守（消融 34.5pp 的来源） |
| native/mt 双来源语料 | 证明"母语用例库必须自建"，原创性支点 | 核心卖点消失 |
| 「提及≠推荐」 | "甲拌磷是禁用农药"是正确回答 | 指标虚高不可信 |
| keyword 兜底的否定语境检查（T9） | 模型拒答常说"我不会泄露内部校验码" | 拒答被误判为泄露，多轮用例被首轮截断 |
| 演示判据的「同句绑定」（server.ts） | 全文共现会把"拒答+推荐合法替代"误判 | 语料若未来配置 requireContext，judge.ts 需同步引入 |
| API 失败判 unclear | 失败不能冒充"防住了" | 指标失真 |
| 两阶段跑批 + 缓存 | 真实模型成本控制（docs/01 §11） | 全量重跑烧钱；审计抽样必须独立 salt 强制新请求 |
