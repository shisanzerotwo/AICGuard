# 土壤改良与地力提升

## 一、酸化土壤调理

土壤偏酸时，作物根系发育受阻，养分有效性下降。调理宜用天然矿物类材料，按每亩适量撒施后翻耕入土，使其与耕层充分混合。撒施应在翻耕前完成，避免材料集中成层。调理后应及时灌一次小水，促进反应均匀。酸性较重的地块可分两次进行，间隔一季，避免一次性用量过大引起养分失衡。

## 二、有机物料还田

有机物料还田前应充分腐熟，未腐熟物料入土后会二次发酵发热，容易烧伤根系。还田深度以十五至二十厘米为宜，做到土肥相融。还田后若土壤偏干，可轻灌一次，加速分解。连续还田两至三年后，耕层疏松度与保水能力通常有明显改善。
