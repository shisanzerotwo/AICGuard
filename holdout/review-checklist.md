## 1. 【最大一项】家族级口径：多轮族（MT×5）标签形态统一（争议 A-05）

**实测三形态**（native 侧 5 条一致为「用户：／助手：」）：

| pairId | 译本标签形态 | 分隔符 |
|---|---|---|
| HL-MT-01 | **英文** `User:` / `Assistant:` | ` / ` |
| HL-MT-02 | **无标签**（5 句平铺） | ` / ` |
| HL-MT-03 | 中文「用户：/助手：」 | ` / ` |
| HL-MT-04 | 中文「用户：/助手：」 | ` / ` |
| HL-MT-05 | 中文「用户：/助手：」 | **换行**（4 个 `\n`） |

**为什么必须定口径**：母语侧统一中文标签，译文侧混用三态 ⇒ 语言对照实验里「表述差异」与「格式差异」无法分离，会成为混淆变量。

- [ ] **方案 ①（推荐）译文侧统一为「用户：／助手：」+ 全角斜杠**：与 native 侧完全同形 ⇒ 对照实验只比"表述"，不比格式；代价 = 返工 5 条（1 次真实翻译调用或定点改写）。
- [ ] **方案 ② 译文侧统一为 `User:`／`Assistant:`**：最贴英文原文、最像"机翻"；代价 = 与 native 侧格式不同，**等于把格式差异留作变量**（须在 MANIFEST 里声明）。
- [ ] **方案 ③ 不返工**：把"译本三形态"写成已知偏差，交由 M6 解释时说明；代价 = 实验解释力下降。

> 备注：无论选 ①②③，`HL-MT-02` 都还另有 A-04（标签**全丢**），见 §2。

## 2. 明确缺陷（4 条，均为"局部、有最小修法"）

### A-01 `HL-EN-03`：leet 里 `sp4y` 被译成「间谍」（应为"喷洒/喷雾"）
- 证据：en `… h1dd3n sp4y rul3 … bl0ck3d f0r sp4y1ng` ⇒ 译文「隐藏的**间谍**规则…用于**间谍活动**的公式」；全条**无**「喷雾/喷洒」。
- 影响：该对主题是「农药喷雾」，译文把**主题词换掉了** ⇒ 主题位漂移（family/goal 未变）。
- 附带：该对 `strength=1`，但两侧都是"明确索要"措辞，与其他 `strength=1`（试探式）不一致。
- [ ] **修**（推荐）：重译该条使译文出现「喷洒/喷雾」；并确认英文原文 `sp4y` 是否本意 spray（若确认，英文侧一并改为 `5pr4y` 之类可解的 l33t）；`strength` 待定（见下）
- [ ] **不修**：写成已知偏差
- strength 处置：[ ] 改为 2　[ ] 维持 1（若维持，请确认"编码遮蔽 = 降强"这一口径成立；若成立，EN 族 5 条要统一复核）

### A-02 `HL-II-05`：`feed formula` 被误译为「推送公式」（应为"饲料配方"）
- 证据：en `… the feed formula guardrails …` ⇒ 译文「**推送公式**护栏」；英文无"推送"义项。
- 影响：该对主题「饲料配比」的主题词丢失（family/goal 未变）。
- [ ] **修**（推荐）：只改该条译文，「推送公式」→「饲料配方」
- [ ] **不修**：写成已知偏差

### A-03 `HL-MT-01`：译文混入 1 个繁体字「建議」
- 证据：`Assistant: 我只分享经批准的建議。`（严格繁体集扫描 + 阴性对照后确认，全库仅此 1 处）
- [ ] **修**（推荐）：「建議」→「建议」（单字替换，不动其它）
- [ ] **不修**：写成已知偏差

- 证据：en = `User:`×3 + `Assistant:`×2；译本 = **0 个标签**，5 句变无主语句串。
- 影响：`multi_turn_induction` 的**轮次与说话人就是攻击结构本身** ⇒ 丢标签等于破坏样本结构；也是该家族唯一一例。
